# Multidecadal trends in phytoplankton biomass and phenology in Southern Ocean water masses

This repository contains the R code and the derived data used in Pouly, M., Le Ster, L., Molinet, M., Gros-Martial, A., Sari El Dine, Z., Bouillot, A., Uitz, J., and Guinet, C. (2026), Multidecadal trends in phytoplankton biomass and phenology in Southern Ocean water masses, Journal of Geophysical Research: Oceans (submitted). The code and data are archived on Zenodo. If you use them, please cite both the article and the archive.

The study combines 26 productive seasons (October to March, from 1998/99 to 2023/24) of satellite chlorophyll-a with a hydrological ecoregionalization of the Southern Ocean built from the temperature and salinity structure of the upper 1000 m. Within this framework, it estimates multidecadal trends in phytoplankton biomass and in the shape of the seasonal cycle using functional data analysis and non-parametric trend estimation.

The analysis is organized in four scripts, to be run in order from the root of the repository. The first script, 01_ecoregionalization.R, projects the monthly temperature and salinity profiles onto B-spline bases, decomposes them with a bivariate functional principal component analysis, clusters the first three modes into eight groups with K-means, and derives the ecoregion boundaries from the inter-month standard deviation of the cluster number. It also produces Figure 2 and Figures S3 to S5. The second script, 02_chl_fda_trends.R, fits a penalized B-spline curve to the 23 eight-day chlorophyll-a composites of each pixel and season, integrates it to obtain a seasonal biomass index, decomposes the normalized curves with a functional principal component analysis to describe phenology, and estimates the trends of the biomass index and of the phenological scores with Sen's slope and the Mann-Kendall test. It also produces Figure S2. The third script, 03_analyses.R, assigns each pixel to its ecoregion and computes the statistics reported in the paper, including Table S1, the ecoregion trajectories, the climatologies, the two-period comparison of the seasonal cycle, the comparison between ecoregions and front-based zones, and the tests of coincidence between trend gradients and ecoregion boundaries. The fourth script, 04_figures.R, produces Figures 1 and 3 to 8 of the paper and Figures S1 and S6 to S13 of the Supporting Information. Intermediate files and figures are written to an outputs folder created by the scripts.

The folder ecoregion_layers contains the layers used in the paper, which can be reused independently of the code: the polygons of the eight hydrological ecoregions, numbered from 1 (subtropical) to 8 (Antarctic), and the inter-month standard deviation of the cluster number on a 0.25 degree grid, whose high values mark the transition zones between ecoregions. Both are in geographic coordinates (WGS84).

The input data are not included and must be downloaded separately. Chlorophyll-a comes from the ESA Ocean Colour Climate Change Initiative, version 6.0, as 8-day composites at 4 km resolution (doi:10.5285/5011d22aae5a4671b0cbc7d05c56c4f0), available from https://www.oceancolour.org/portal/. The NetCDF files, one per composite with the start date of the composite in the file name, go in data/occci_v6_8day. Temperature and salinity come from the Global Ocean Ensemble Physics Reanalysis, product GLOBAL_MULTIYEAR_PHY_ENS_001_031 (doi:10.48670/moi-00024), available from the Copernicus Marine Service after free registration. The monthly ensemble means of temperature and salinity over 0 to 1000 m, south of 30°S, for October to March between October 1998 and March 2024, go in data/copernicus_grep.

The code requires R 4.5.1 or later and the CRAN packages dplyr, purrr, ggplot2, patchwork, data.table, ncdf4, fda, cluster, terra, sf, here, pbapply, trend, mblm, ggpattern, ggridges, rnaturalearth, colorspace, viridisLite, sysfonts and showtext. Two packages are installed from GitHub with the remotes package: fda.oce (EPauthenet/fda.oce) and orsifronts (mdsumner/orsifronts). The exact versions used for the paper are listed in session_info.txt. The figures use the Latin Modern Roman fonts if the files lmroman10-regular.otf and lmroman10-bold.otf are placed in a fonts folder, and a default serif font otherwise. The first two scripts process several million profiles and seasonal curves and require a large amount of memory (they were run on a workstation with XX GB of RAM); the last two only use the outputs of the previous scripts.
